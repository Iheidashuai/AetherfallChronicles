# MythicRealm

iOS 单机 RPG 游戏 — 西方魔幻题材，2D 像素风，即时动作战斗。

通过机器人模拟多人在线氛围，让单机也能感受到 MMO 的热闹。

## 技术栈

- Swift + SpriteKit（游戏引擎）
- SwiftUI（UI 系统）
- SQLite / GRDB.swift（数据存储）
- ECS 架构
