### 副本详情页

详情页展示以下信息：

- 副本名称、描述、难度
- 推荐等级、推荐战力、玩家当前战力
- 等级或战力不足时展示风险提示，但不禁止挑战
- 怪物清单：怪物名、等级、HP、力量、数量、Boss 标记
- 可能掉落：从副本房间内所有怪物的掉落表聚合，按品质和需求等级排序，同一物品只显示一次，掉率取最高值

### 挑战规则

- 点击「挑战」后进入当前选中的副本
- 战斗 HUD 的房间数来自当前副本配置
- 如果选中副本 id 丢失，回退到第一个副本，避免崩溃
- 当前版本不做副本解锁，不做每日次数限制，不做首通奖励

## 副本内部流程（5 房间示例）

```
房间1：小怪 ×5-8（热身）
   ↓
房间2：小怪 ×8-10 + 精英怪 ×1（学习精英机制）
   ↓
房间3：陷阱房/解谜（环境互动，如躲避落石、踩开关）
   ↓
房间4：精英怪 ×2 + 小怪浪（压力测试）
   ↓
[隐藏房间]：20% 概率出现岔路，有宝箱 + 稀有怪
   ↓
房间5：Boss战（多阶段）
```

## Boss 设计原则

- 每个 Boss 2-3 个阶段（血量 100%/50%/20% 切换）
- 每阶段新增 1-2 个机制
- 有明确的攻击预警（地面红圈/蓄力动画）
- 必须通过走位 + 时机判断来规避，而非纯堆数值

### Boss 示例 — 腐败树人王（第一章最终 Boss）

- 阶段1（100%-50%）：挥击（正面锥形）+ 根须突刺（地面延迟攻击）
- 阶段2（50%-20%）：召唤小树人 + 毒雾区域（缩小安全区）
- 阶段3（20%-0%）：狂暴，攻速加快 + 全屏根须网格（需在缝隙中移动）

## 副本奖励设计

**首通奖励（仅第一次通关）：**
- 普通首通：大量经验 + 金币 + 1 件蓝装保底
- 困难首通：钻石 + 1 件紫装保底
- 地狱首通：稀有称号 + 1 件紫装/橙装

**日常奖励：**
- 每个副本每天前 3 次有额外奖励
- 3 次之后掉落减半（防止无限刷）

## 任务系统

### 任务类型

- **主线任务**：推进剧情，解锁新区域
- **支线任务**：NPC 给予，奖励装备/金币
- **日常任务**：每日（游戏日）刷新 5 个随机任务
- **成就系统**：长期目标奖励

### 日常任务池

- 击杀 X 只怪物
- 通关指定副本 1 次
- 强化装备 N 次
- 在拍卖场购买/出售物品
- 合成宝石 N 次
- 收集指定材料
