# 全服通告系统

## 设计目标

通过全服通告制造「社交压力」和成就感，驱动玩家追求目标。
同时机器人也会触发通告，让世界显得热闹。

## 通告触发规则

### 装备强化通告

| 强化等级 | 通告内容 | 展示方式 |
|----------|----------|----------|
| +7 | 恭喜 [名字] 将 [装备名] 强化至 +7！ | 系统频道（黄色文字） |
| +10 | 恭喜 [名字] 将 [装备名] 强化至 +10！实力大增！ | 系统频道（橙色） + 屏幕顶部横幅 |
| +12 | 恭喜 [名字] 将 [装备名] 强化至 +12！全服瞩目！ | 全屏特效公告（红色） |
| +15 | 传奇时刻！[名字] 将 [装备名] 强化至 +15 满级！！！ | 全屏特效 + 烟花 + 持续 5 秒 |

### 装备获取通告

| 触发条件 | 通告内容 | 展示方式 |
|----------|----------|----------|
| 获得紫色(史诗)装备 | 恭喜 [名字] 在 [副本名] 获得史诗装备 [装备名]！ | 系统频道（黄色） |
| 获得橙色(传说)装备 | 恭喜 [名字] 获得传说装备 [装备名]！万中无一！ | 全屏特效（金色） |
| 集齐套装最后一件 | [名字] 集齐了 [套装名] 全套！套装之力觉醒！ | 屏幕横幅（紫色） |
| 首通地狱副本 | [名字] 首次通关 [副本名] 地狱难度！ | 屏幕横幅（橙色） |

### 其他通告

## 展示层次（三级）

```
第一级：系统频道文字（黄色）
  → 强化+7、获得紫装、等级整十、宝石合成
  → 只在聊天频道滚动显示

第二级：屏幕顶部横幅（3秒自动消失）
  → 强化+10、首通地狱、集齐套装
  → 战斗中也能看到

第三级：全屏特效公告（居中大字 + 粒子特效，5秒）
  → 强化+12以上、获得橙装、排行榜登顶、世界Boss击杀
  → 有动画效果
```

## 机器人对通告的反应

当通告出现后，1-3 个 bot 在 15-30 秒内在世界频道做出反应：

```
示例 — 通告：恭喜 [玩家] 将 [黑铁重剑] 强化至 +10！

[friendly] → "牛啊 {player}！+10了，什么时候带我打副本"
[showoff]  → "我的也快+10了，等我两天"
[casual]   → "有钱人...我+7都升不上去"
[newbie]   → "强化石都是哪刷的啊，我都不够用"
[hardcore] → "+10之后性价比就低了，建议攒着搞下一件"
[merchant] → "需要强化石吗，我这有存货"
```

## 机器人触发通告频率

| 通告类型 | 频率 | 说明 |
|----------|------|------|
| bot 强化到 +7 | 每游戏日 1-2 个 | 常见，维持热闹感 |
| bot 强化到 +10 | 每 3-5 游戏日 1 个 | 偶尔出现，刺激玩家 |
| bot 强化到 +12 | 每 10-15 游戏日 1 个 | 稀有，引发频道讨论 |
| bot 获得紫装 | 每游戏日 2-3 个 | 维持基础热度 |
| bot 获得橙装 | 每 7-10 游戏日 1 个 | 极稀有大事件 |
| bot 登顶排行榜 | 根据实际变动 | 动态触发 |

**玩家体感**：每隔 2-3 分钟（现实时间）能看到一条全服通告。

## 通告驱动的正循环

```
看到通告 → 产生目标感（"我也要+10"）
    ↓
投入行动 → 刷金币/买材料/打副本
    ↓
达成目标 → 自己触发通告
    ↓
获得成就感 + bot 恭喜 → 追求下一个目标
```
