# 经济系统

## 设计目标

单机经济的核心矛盾：既不能通货膨胀（金币泛滥无意义），也不能太紧缩（玩家刷不动）。
设计原则：**略微入不敷出**，让玩家始终有赚钱动力。

## 货币体系

| 货币 | 定位 | 获取方式 | 用途 |
|------|------|----------|------|
| 金币 | 主要流通货币 | 打怪/卖装备/任务 | 强化、镶嵌、商店、拍卖场 |
| 钻石 | 稀有货币 | 成就/日常/挑战 | 祝福石、扩容、外观、重置 |
| 荣誉点 | 排行榜货币 | 周排行结算 | 兑换特殊外观/称号 |

## 金币产出模型

以「每小时游玩」为基准：

| 来源 | 每小时产出（1级基准） | 等级系数 |
|------|----------------------|----------|
| 打怪掉落 | 100 金 | ×玩家等级 |
| 卖白/绿装备 | 50 金 | ×玩家等级 |
| 日常任务(5个) | 300 金(一次性) | ×玩家等级 |
| 拍卖场出售 | 波动 | 取决于市场 |

**示例：30 级玩家每小时产出**
- 打怪：100 × 30 = 3,000 金
- 卖装：50 × 30 = 1,500 金
- 合计约 4,500 金/小时 + 日常 9,000 金/天（游戏日）

## 金币消耗去向

| 消耗 | 金额设计 | 说明 |
|------|----------|------|
| 强化装备 | L² × N × 10 | 最大的金币黑洞 |
| 宝石取出 | 宝石等级 × 1,000 | 换宝石有成本 |
| 拍卖场手续费 | 上架5% + 成交10% | 抽走系统内货币 |
| 药水消耗 | 每副本 200-500 金 | 持续消耗 |
| 神秘商人 | 高价稀有物 | 大额吸金 |
| 传送/复活 | 等级 × 50 | 小额持续消耗 |
| 装备修理 | 死亡后修理费 | 持续消耗 |

## 核心数值公式

### 物品价值

```
物品价值 = 基础价 × (1 + 等级 × 0.1)^1.5 × 品质系数

品质系数：白=1, 绿=2, 蓝=5, 紫=15, 橙=50
```

### 强化费用曲线

```
强化费用(等级N, 装备等级L) = L² × N × 10

30级装备强到+10总花费：
+1: 9,000  +2: 18,000  +3: 27,000  +4: 36,000  +5: 45,000
+6: 54,000  +7: 63,000  +8: 72,000  +9: 81,000  +10: 90,000
合计：495,000 金 ≈ 5-6 小时刷怪收入（不含失败重试）
```

### 拍卖场定价

```
机器人上架价 = 物品价值 × random(0.7 ~ 1.3)
超值物品(5%概率) = 物品价值 × random(0.3 ~ 0.5)
```

## 通胀控制机制

| 机制 | 作用 |
|------|------|
| 强化失败消耗 | 高强化等级是最大的金币黑洞 |
| 拍卖场税收 | 每笔交易抽 15%，永久消失 |
| 每日副本收益上限 | 前 3 次有额外奖励，之后减半 |
| 装备修理费 | 死亡/副本后修理花钱 |
| 神秘商人 | 高价稀有物大额吸金 |

**健康指标：** 玩家金币存量不应长期超过 10 小时收入量。

## 钻石经济

**获取：**

| 获取方式 | 数量 |
|----------|------|
| 日常任务全完成 | 30 钻/天 |
| 成就解锁 | 50-500 钻（一次性） |
| 首通副本（困难/地狱） | 100 钻（一次性） |
| 周排行榜奖励 | 50-200 钻 |

**消耗：**

| 用途 | 价格 |
|------|------|
| 祝福石(强化保护) | 50 钻/个 |
| 背包扩容 | 100 钻/10 格 |
| 角色外观 | 200-500 钻 |
| 重置技能点 | 80 钻 |
