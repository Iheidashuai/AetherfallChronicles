# 终局 & 赛季循环 设计提案

> 状态：**设计提案（未实现）**。当前已实现的终局现状见 [specs/10-endgame-system.md](../specs/10-endgame-system.md)。
> 目标：补上项目最大的产品空洞——**满级（90）后没有长期目标**、**竞争没有真实输赢**、**没有赛季循环**。

## 1. 问题陈述（来自调研）

| 问题 | 现状 | 后果 |
|------|------|------|
| 无赛季循环 | 只有 rift 周常宝箱（`player_rift_weekly_reward`），无重置 / 天梯快照 / 赛季奖励 | 满级后无"重新开始"的动机，留存断崖 |
| 竞争无真实输赢 | 机器人由实时打分驱动，整体可被玩家超越；战力榜只升不降 | 榜单是背景装饰，不是动力 |
| 机器人不会"赢" | 没有"宿敌"会反超你、抢你排名 | MMO 幻觉缺乏紧张感 |
| 终局数值无限缩放缺失 | rift 有分层但无 paragon / 无限词缀 | 顶层玩家很快触顶 |

设计原则：**在不破坏"单机也热闹"体验的前提下，给世界加入"会失去的东西"**。

## 2. 赛季循环（Season Loop）

### 2.1 时长与节奏
- **一个赛季 = 14 天现实时间**（可配置）。短到能反复体验"开荒→冲榜→结算"，长到有养成深度。
- 赛季由后端调度推进（复用现有 `@Scheduled` 体系），到点自动结算 + 开新赛季。

### 2.2 重置 vs 保留
| 重置（赛季清零） | 保留（永久账号） |
|------------------|------------------|
| 战力榜 / 竞技场 rating | 角色等级、技能、藏品图鉴 |
| 赛季积分（新货币，见下） | 装备与强化（**不**清空，避免挫败） |
| rift 赛季最高层进度 | 历史赛季成就 / 称号 / 段位徽章 |

> 取舍：装备不清零（这是单机，清装备会劝退）。赛季竞争清零的是**排名与赛季积分**，让每赛季"重新冲"。

### 2.3 天梯快照与结算
- 赛季结束时对战力榜 / 竞技场榜做 **快照**（新表 `season_ladder_snapshot`），冻结名次。
- 按名次发**赛季奖励**：赛季积分、专属称号、段位徽章、外观（外观系统需补，见 §5 风险）。
- 段位制（参考成熟天梯）：青铜 / 白银 / 黄金 / 铂金 / 钻石 / 大师 / 王者，按赛季最终 rating 归档。

### 2.4 赛季积分（新货币）
- 来源：赛季内打 rift / 竞技场 / 冲榜结算。
- 用途：赛季商店买**非数值**奖励（外观、称号、图鉴解锁），避免破坏装备经济。
- 跨赛季保留（养成感），但不能买战力（保持公平）。

## 3. 竞争张力（让机器人"会赢"）

核心改动在 **`RobotBrainService` 的打分权重**（遵守 [AGENTS.md] 的"新玩法要让机器人感知"规则）：

### 3.1 可反超的宿敌（Nemesis）
- 每个玩家分配 **1-2 个"宿敌"机器人**，rating / 战力贴着玩家 ±5%。
- 宿敌的成长权重对玩家**敏感**：你冲榜，它加速追；你掉线，它也冲（**会真的反超你的排名**）。
- 宿敌反超时触发**全服通告 + 频道挑衅**（"@你 我把你挤下去了😏"），制造"我要夺回来"的动机。
- 宿敌可在竞技场被你直接挑战（已实现 `POST /api/arena/challenge/{targetId}`）——给"复仇"一个出口。

### 3.2 段位有升有降
- 竞技场 rating 引入**降段风险**：连败 / 长期不打会掉段。当前 `arena_profile` 只有 rating，加"赛季峰值段位"与"保护局"。
- 战力榜引入**衰减**：长期不更新装备的机器人/玩家缓慢下滑，给活跃者腾位。

### 3.3 橡皮筋的"诚实"版本
保留旧设计的善意（不让回归玩家绝望），但区分：
- **下方机器人**：你稳定时会缓慢追上（"不进则退"），制造压力。
- **宿敌**：始终贴身，能反超。
- **顶部机器人**：成长略低于玩家峰值速度，让肝帝够得着 Top 3。
- 玩家连续掉线 → 全局机器人降速（现有意图），但**宿敌不降速**（保留紧张感）。

## 4. 无限缩放终局（Rift Paragon）

满级后数值出口，挂在已实现的 rift 上：

- **paragon 等级**：90 级后经验转化为 paragon 点，分配到小幅永久加成（攻/防/暴击/掉率），无硬上限、边际递减。赛季**不**清零 paragon（账号养成），但**赛季积分榜**单独排名当季 paragon 收益，保证公平。
- **rift 无限层 + 随机词缀**：复用 `rift_modifier_config`，高层叠加随机危险词缀（参考已实现的敌人机制 `shield_phase` / `enrage_50` / `heavy_every_3`），每层难度分 + 奖励加成递增。
- **每周 rift 终点墙**：当前周常宝箱（`player_rift_weekly_reward`）升级为"赛季内每周最高层"累计，喂赛季积分。

## 5. 实现挂载点（具体到表 / 服务）

| 模块 | 改动 |
|------|------|
| 新表 `season`（id, 开始/结束时间, 状态） | 赛季生命周期 |
| 新表 `season_ladder_snapshot`（season_id, player_id, board, rank, tier） | 结算冻结名次 |
| 新表 `player_season_progress`（season_id, player_id, season_points, peak_tier, paragon_points） | 赛季养成 |
| `arena_profile` | 加 `season_peak_tier`、降段保护字段 |
| `LeaderboardService` | 加战力衰减 + 赛季快照读取 |
| `RobotBrainService` 打分器 | 加宿敌权重、对玩家排名敏感的成长、降段行为 |
| 新 `SeasonService`（`@Scheduled`） | 赛季切换 + 结算 + 发奖 |
| `global_announcement` | 新增 kind：`season`（开赛/结算）、`nemesis`（反超挑衅） |
| 前端 | 赛季横幅、段位徽章、赛季积分商店、宿敌卡片（竞技场页） |

> **机器人感知（必做）**：按 AGENTS.md，新增赛季 / 段位 / 宿敌后，必须更新机器人决策——让机器人也参与赛季冲榜、竞技场升降段、作为宿敌反超玩家。否则赛季榜会"只有玩家在动"，幻觉破裂。

## 6. 外观系统依赖（风险）

赛季奖励 / 赛季积分商店大量依赖**外观系统**，而当前**没有外观系统**（旧 spec 的钻石外观从未实现）。两个选项：
- **MVP**：先用**称号 + 段位徽章 + 图鉴解锁**作为非数值奖励（实现成本低，无需美术）。
- **完整**：补一套外观（边框 / 称号 / 战斗特效皮肤）——需要美术资源，排在 MVP 之后。

## 7. 分期落地

| 阶段 | 内容 | 价值 |
|------|------|------|
| **P1（赛季骨架）** | `season` + 切换调度 + 战力榜赛季快照 + 段位归档 + 称号奖励 | 立刻有"赛季感"，无需外观 |
| **P2（竞争张力）** | 宿敌系统 + 竞技场升降段 + 机器人打分接入 | 让竞争"会输"，强化幻觉 |
| **P3（无限终局）** | paragon + rift 无限层词缀 + 赛季积分商店（称号/图鉴） | 满级后长期目标 |
| **P4（外观）** | 外观系统 + 赛季积分外观奖励 | 付费 / 炫耀闭环（需美术） |

## 8. 成功指标

- 满级玩家在赛季中后期仍有明确的"下一个目标"（段位 / paragon / 宿敌复仇）。
- 战力榜 / 竞技场榜**会下降**，玩家能感到"不进则退"。
- 每赛季至少触发一次"被宿敌反超 → 夺回"的情绪弧。
- 赛季结算的全服通告成为重复回流的钩子。
