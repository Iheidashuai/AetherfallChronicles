EXTERNAL DEPENDENCIES (Anti-Corruption Layer via Application Service)
├─ PlayerService        → Load player, apply rewards
├─ InventoryService     → Load equipment, calculate combat power, add loot
├─ GameConfigService    → Load dungeon/monster/item configs
└─ QuestService         → Record quest events

COMBAT FLOW
1. Load player + equipment → Calculate combat power
2. Calculate pressure based on power ratio
3. For each room:
   a. For each monster:
      - Scale HP/attack by pressure
      - Execute turn-based combat (max 18 rounds)
      - Apply damage with variance + crits
      - Check for player death
      - Award exp/gold on victory
      - Calculate loot drops
   b. Recover HP between rooms
4. Calculate rating (S/A/B/C/F)
5. Fire domain events
6. Record quest events

IDEMPOTENCY
- requestId used for duplicate detection
- Returns cached result if found in DungeonRunRepository
